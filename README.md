# 研学本 · 部署教程（零编程基础版）

## 这是什么

一个「知识学习 + 做题整理」的 APP，覆盖上海高中 **语文、数学、英语、物理、化学、生物** 六科。

- 全部数据存在你自己手机/电脑的浏览器里，不上传任何服务器
- 免费，无广告，无账号体系

---

## 功能一览

| 功能 | 说明 |
|---|---|
| 📝 做题 | 选择题库 / 综合混练，支持单选、填空、判断三种题型 |
| 🔁 错题本 | 答错自动收录，按 **1天 → 3天 → 7天 → 30天** 间隔重复提醒，答对自动推迟，答错重置 |
| 📚 知识点 | 按科目整理概念、公式、方法，支持搜索和标签 |
| 📊 统计 | 各科正确率、近 7 天做题量 |
| 💾 备份 | 一键导出 JSON 备份文件，换设备可导入恢复 |
| ➕ 自行录题 | 支持拍照/截图录题（图片自动压缩） |
| ✨ AI 出题 | 内置提示词生成器，配豆包 / Kimi 等任意 AI 自动出题，粘贴回答一键入库 |
| ✨ AI 录错题 | 拍错题照片发豆包，识别成题目一键入库（支持简单【题】【答】块格式） |
| ✨ 解答题 | 主观大题：写过程 → 对答案自评 → 答错自动进错题本 |

自带 17 道示例题 + 11 条知识点，开箱即可体验，之后逐步录入自己的题。

## 部署（共 3 步，约 10 分钟）

### 第 1 步：注册 GitHub

1. 打开 <https://github.com>，点 **Sign up**
2. 用邮箱注册，用户名随意（记住它，下面要用）
3. 免费账号即可，全程 0 费用

### 第 2 步：上传文件

1. 登录后，点右上角 **+** → **New repository**（新建仓库）
2. **Repository name** 填：`study-app`（必须完全一致）
3. 勾选 **Public**，点 **Create repository**
4. 在新页面点 **uploading an existing file** 链接
5. 把本目录下的 `index.html` 拖进去
6. 点绿色按钮 **Commit changes**

### 第 3 步：开启网页访问

1. 仓库页面点 **Settings**（顶部标签）
2. 左侧菜单点 **Pages**
3. **Source** 选 **Deploy from a branch**，**Branch** 选 **main / (root)**，点 **Save**
4. 等 1-2 分钟，刷新页面，顶部会出现绿色提示：
   `Your site is live at https://你的用户名.github.io/study-app/`

**这个网址就是你的 APP。** 手机电脑浏览器打开即用。

1. 手机 Chrome 浏览器打开上面的网址

## 常见问题

**Q：换手机数据会丢吗？**
会。数据只存在本机浏览器。换机前在「我的 → 导出备份」，新设备上「导入备份」即可恢复。

**Q：不小心清了浏览器数据怎么办？**
定期导出的备份文件就是救命稻草。没有备份则无法恢复——务必养成导出习惯。

**Q：图片题占空间吗？**
APP 会自动把图片压缩到 800px 内。存几百道题通常没问题，若提示存储不足，先导出备份再清理旧图。

**Q：能多人共用吗？**
数据在本机，天然单用户。给孩子用就装在孩子手机上，你录入题目后导出备份给孩子导入。

**Q：怎么用 AI 自动出题？**
底部「我的 → AI 出题助手」：选科目、填范围、设数量难度 → 复制提示词发给豆包 / Kimi → 把 AI 的回答原样粘回来 → 自动解析入库。格式不对的题会提示原因并跳过。

**Q：AI 录错题支持什么格式？**

两种方式都支持：
1. JSON 数组（AI 出题模式）
2. 简单块格式（录错题模式推荐，人也能看懂手改）：一题一块

```
【题】题干内容
【选】A. 选项一 B. 选项二 C. 选项三 D. 选项四（选择题才需要）
【答】B（选择题填字母，填空多个答案用/分隔，判断题填 对 或 错）
【析】详细解析
【型】解答（可选，标记为解答题）
【标】知识点标签，逗号分隔
```

多块连续粘贴即可。不符合格式的题会提示原因并跳过，不污染题库。

**Q：解答题怎么判分？**

解答题无法自动判分。流程：写下解答过程 → 提交查看参考答案 → 自评"答对了 / 没答好"。"没答好"会进错题本参与复习。

**Q：网页打不开？**
GitHub Pages 偶尔抽风，刷新即可。长期备用方案：把 index.html 直接发给任何人，双击本地打开同样能用（只是不能"添加到主屏幕"）。
